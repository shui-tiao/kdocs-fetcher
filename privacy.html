金山文档拉取器 · Chrome / Edge 浏览器扩展

最后更新：2026 年 10 月 28 日

一、简介

金山文档拉取器（下称"本扩展"）是一款浏览器扩展，帮助用户快速从自己的 金山文档 表格中拉取指定字段的最新一条记录，并支持一键复制到剪贴板。

🔒 核心原则：本扩展不收集任何个人身份信息，不跟踪用户浏览行为， 所有数据处理都在用户本地浏览器或用户本人配置的金山文档 Webhook 服务器上完成。

二、我们处理哪些信息？

1. 用户主动配置的本地设置

为了正常工作，本扩展会将以下内容保存在浏览器本地存储中（chrome.storage.local）：

字段用途标签
Webhook 链接用户自己的金山文档脚本 Webhook 地址本地存储
脚本令牌（Token）调用 Webhook 时的身份凭证本地存储
要拉取的字段列表用户指定的字段名（如"内容"、"机构"）本地存储
数据位置偏好最新记录位于表格顶部还是底部本地存储
自动复制字段用户选定的自动复制字段名（可选）本地存储

2. 用户的金山文档表格数据（临时）

  • 用户每次点击扩展图标时，扩展会向用户配置的 Webhook 发起一次 HTTPS 请求。
  • Webhook 返回的最新一条记录仅在扩展弹窗打开期间存在于浏览器内存中， 弹窗关闭或刷新后立即清除，不会写入任何持久化存储。

3. 明确不处理的信息

  • ❌ 浏览器历史记录、书签、已安装扩展列表
  • ❌ 用户访问过的任何网页内容
  • ❌ IP 地址、设备标识符、地理位置
  • ❌ 完整表格数据（仅拉取最新一条）
  • ❌ Cookie / LocalStorage / SessionToken（本扩展不使用也不读取）

三、网络通信

唯一的出站请求

本扩展只会向以下两类地址发送 HTTPS 请求：

  • https://www.kdocs.cn/api/v3/ide/file/.../script/.../sync_task —— 即用户自己配置的金山文档 Webhook 接口，用于拉取最新一条记录。

请求体仅包含：{ Context: { argv: { fields, order } } }，即用户配置的字段名和排序偏好。

不会向任何第三方发送数据

  • 没有 Google Analytics、Mixpanel、友盟等分析 SDK
  • 没有自建后端服务器接收数据
  • 没有任何广告或联盟追踪像素

host_permissions 仅限于 https://www.kdocs.cn/*，Chrome / Edge 会阻止扩展访问其他域名。

四、扩展权限说明

安装本扩展时，Chrome / Edge 会用通俗语句列出它申请的权限。部分提示文字（例如"阻止任何页面上的内容"） 容易让人误以为扩展会干扰网页，特此逐项说明本扩展的实际用途：

权限浏览器提示实际用途
storage 读取和更改您在本扩展中的数据 仅保存 Webhook 地址、令牌、字段列表等本地配置（见第二节）。
declarativeNetRequest 阻止任何页面上的内容 仅用于修改发往金山文档接口的请求头，不拦截、不读取、不修改任何网页内容（详见下方说明）。
host_permissions
（https://www.kdocs.cn/*）		 读取和更改 www.kdocs.cn 上的数据 仅允许向金山文档 Webhook 发起 HTTPS 请求，无法访问其他网站。

关于"阻止任何页面上的内容"

该提示由 declarativeNetRequest 权限触发。本扩展的规则文件 （rules.json）中只有一条规则，作用是：

  • 仅匹配 www.kdocs.cn/api/v3/ide/ 下的 XMLHttpRequest 请求；
  • 把该请求的 Origin 请求头设置为 https://www.kdocs.cn。

这样做的原因是：从扩展弹窗直接请求金山文档 Webhook 时，浏览器会把 Origin 标记为 chrome-extension://…，金山文档服务端的跨域校验会拒绝该请求；调整这一个请求头即可让 用户自己配置的 Webhook 正常返回数据。

本扩展没有添加任何 block、redirect、allow 等拦截规则，不会屏蔽任何网站的请求、广告或页面元素， 也不会读取或修改任何网页的 DOM 内容。该权限全部作用范围仅限于上述金山文档接口的请求头。

五、数据保留与删除

用户可以随时清除所有数据

  • 打开 Chrome / Edge 的 扩展管理页 → 找到本扩展 → 点击"详情"
  • 点击"扩展选项" → 在弹出的设置页中删除现有字段、清空 Webhook 和令牌后保存
  • 或者直接"移除扩展"，卸载后浏览器会自动清除 chrome.storage.local 中的所有条目

内存数据

弹窗关闭、浏览器重启或 Tab 被回收时，当前显示的表格数据会立即从内存中释放，无需额外操作。

六、第三方服务

本扩展依赖以下第三方服务来完成核心功能，请注意阅读它们各自的隐私政策：

  • 金山文档（WPS Office） —— 用户配置的 Webhook 运行在金山文档的云端脚本编辑器中。 请查阅 WPS 隐私政策。
  • Chrome / Edge 浏览器 —— 本地存储、剪贴板访问均通过浏览器原生 API 完成。

本扩展不与上述第三方共享任何额外信息，仅向金山 Webhook 发送必要的字段名参数。

七、未成年人保护

本扩展未面向 13 岁以下的未成年人设计。我们不会有意收集未成年人的个人信息。 但本扩展实际上只存储用户主动填入的工作相关配置，且不执行任何年龄识别逻辑。 若您是家长或监护人，请根据实际情况决定是否允许使用。

八、隐私政策的变更

若本隐私政策发生变更，我们会：

  • 在本页面顶部更新"最后更新"日期
  • 在扩展的版本更新日志中说明变更内容
  • 重大变更时（如开始收集任何新信息），会在下一版本的扩展弹窗中主动提示用户
