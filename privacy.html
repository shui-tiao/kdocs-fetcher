金山文档拉取器 · Chrome / Edge 浏览器扩展

一、简介

金山文档拉取器（下称"本扩展"）是一款浏览器扩展，帮助用户快速从自己的 金山文档 表格中拉取指定字段的最新一条记录，并支持一键复制到剪贴板。

🔒 核心原则：本扩展不收集任何个人身份信息，不跟踪用户浏览行为， 所有数据处理都在用户本地浏览器或用户本人配置的金山文档 Webhook 服务器上完成。

二、我们处理哪些信息？

1. 用户主动配置的本地设置

为了正常工作，本扩展会将以下内容保存在浏览器本地存储中（chrome.storage.local）：

字段用途标签
Webhook 链接用户自己的金山文档脚本 Webhook 地址本地存储
脚本令牌（Token）调用 Webhook 时的身份凭证本地存储
要拉取的字段列表用户指定的字段名（如"内容"、"机构"）本地存储
数据位置偏好最新记录位于表格顶部还是底部本地存储
自动复制字段用户选定的自动复制字段名（可选）本地存储

2. 用户的金山文档表格数据（临时）

  • 用户每次点击扩展图标时，扩展会向用户配置的 Webhook 发起一次 HTTPS 请求。
  • Webhook 返回的最新一条记录仅在扩展弹窗打开期间存在于浏览器内存中， 弹窗关闭或刷新后立即清除，不会写入任何持久化存储。

3. 明确不处理的信息

  • ❌ 浏览器历史记录、书签、已安装扩展列表
  • ❌ 用户访问过的任何网页内容
  • ❌ IP 地址、设备标识符、地理位置
  • ❌ 完整表格数据（仅拉取最新一条）
  • ❌ Cookie / LocalStorage / SessionToken（本扩展不使用也不读取）

三、网络通信

唯一的出站请求

本扩展只会向以下两类地址发送 HTTPS 请求：

  • https://www.kdocs.cn/api/v3/ide/file/.../script/.../sync_task —— 即用户自己配置的金山文档 Webhook 接口，用于拉取最新一条记录。

请求体仅包含：{ Context: { argv: { fields, order } } }，即用户配置的字段名和排序偏好。

不会向任何第三方发送数据

  • 没有 Google Analytics、Mixpanel、友盟等分析 SDK
  • 没有自建后端服务器接收数据
  • 没有任何广告或联盟追踪像素

host_permissions 声明了 https://www.kdocs.cn/* 与 <all_urls>， 但扩展主动发起的网络请求只有金山文档 Webhook 一处。 <all_urls> 仅用于「获取数据并粘贴」功能向当前页面写入文本， 不会用于请求任何其他服务器。

右键粘贴功能收到的数据流向为：金山文档 Webhook → 扩展后台 → 当前标签页的输入框。 数据不经过任何中转服务器，也不会被额外保存。

四、扩展权限说明

安装本扩展时，您的浏览器会列出它申请的权限。向您说明本扩展的实际用途：

权限浏览器提示实际用途
storage 读取和更改您在本扩展中的数据 仅保存 Webhook 地址、令牌、字段列表等本地配置。
declarativeNetRequest 阻止任何页面上的内容 仅用于修改发往金山文档接口的请求头使其符合规范
sidePanel 在侧边栏中显示内容 用于在浏览器侧边栏中打开本扩展自带的界面（默认为数据查看主界面 popup.html），用户也可在设置中选择「弹窗」方式打开。不支持侧边栏的浏览器会自动回退为普通弹窗。不读取、不修改任何网页内容。
contextMenus 向右键菜单添加选项 仅在用户于设置中主动开启「向右键菜单增加获取数据并粘贴功能」后，向网页输入框的右键菜单添加一项「获取数据并粘贴」。用户关闭该选项后菜单立即移除；扩展不会向其他场景的右键菜单添加任何条目，也不读取右键菜单中的其他内容。
scripting 读取和更改您在所有网站上的数据 仅用于执行上述「获取数据并粘贴」功能：把用户主动配置字段的值填入当前页面中用户右键点击（或已聚焦）的输入框。扩展不会主动注入脚本到任意网页，仅在用户点击该右键菜单项时，对当前标签页按需注入一个内容脚本，用于显示进度气泡并写入文本。
host_permissions
（https://www.kdocs.cn/*）		 读取和更改 www.kdocs.cn 上的数据 用于向金山文档 Webhook 发起 HTTPS 请求。除该地址外，扩展不会主动发起任何其他网络请求。
host_permissions
（<all_urls>）		 读取和更改您在所有网站上的数据 仅为支持「获取数据并粘贴」功能而申请。内容脚本（content.js）只做三件事：接收后台传来的、用户自己配置字段的文本值；在页面上显示一个进度气泡；把该文本写入用户右键点击的输入框。它不读取页面其他内容、不读取任何登录凭证或 Cookie、不修改页面其他元素，也不会把任何网页数据传输到扩展外部或第三方。若用户从未启用该右键功能，此权限不会被实际使用。

本扩展没有添加任何 block、redirect、allow 等拦截规则，不会屏蔽任何网站的请求、广告或页面元素。 声明为 <all_urls> 的内容脚本仅服务于用户主动启用的「获取数据并粘贴」功能， 其唯一副作用是在用户点击右键菜单项时向当前输入框写入一段文本。

五、数据保留与删除

用户可以随时清除所有数据

  • 打开 Chrome / Edge 的 扩展管理页 → 找到本扩展 → 点击"详情"
  • 点击"扩展选项" → 在弹出的设置页中删除现有字段、清空 Webhook 和令牌后保存
  • 或者直接"移除扩展"，卸载后浏览器会自动清除 chrome.storage.local 中的所有条目

内存数据

弹窗关闭、浏览器重启或 Tab 被回收时，当前显示的表格数据会立即从内存中释放，无需额外操作。

六、第三方服务

本扩展依赖以下第三方服务来完成核心功能，请注意阅读它们各自的隐私政策：

  • 金山文档 请查阅 金山文档隐私政策。
  • 您的浏览器

本扩展不与上述第三方共享任何额外信息，仅向金山 Webhook 发送必要的字段名参数。
