01 FEATURES

小而准的效率工具

不为表格再造一个客户端，只解决一件事：让你最新的那条记录，用最短路径到达剪贴板。

一键拉取

点击工具栏图标即刻拉取，无需打开网页、翻找表格。支持开启「点击图标自动拉取」，图标即入口。

自动复制

指定「自动复制字段」后，打开即复制、粘贴即用；多个字段可整段复制，字段名自动跟随。

字段随你定义

按字段名、列字母或列号定位，支持 显示名=列字母 与 :date 转可读时间，一次配置长期生效。

双表格模式

多维表格按字段名取值，调整列顺序、视图排序均不影响；电子表格自动识别表头，兼容两种形态。

六步配置向导

内置带截图的分步向导：部署脚本、生成令牌、填入配置一气呵成，全程约 5 分钟。

锁定与迁移

6 位 PIN 一键锁定，锁定后零请求；配置可加密迁移到新设备，换机不重新配置。

02 HOW IT WORKS

数据只在你的账号里流转

拉取动作由你表格里的 AirScript 脚本完成，扩展只负责触发与展示 —— 没有第三方服务器经手你的数据。

1

触发

点击浏览器工具栏上的扩展图标，弹出「最新记录」面板。

2

直连

扩展向 www.kdocs.cn 发起 webhook 同步请求，携带你的脚本令牌。

3

执行

你部署在表格中的 AirScript 脚本读取指定字段的最新一行并回传。

4

到手

字段渲染进弹窗，自动复制字段同步写入剪贴板，整个链路秒级完成。

03 GET STARTED

六步上手，约五分钟

装好扩展后，跟随内置配置向导走一遍即可；这里先给你预览全流程。

01

安装扩展

前往 Edge 加载项商店，点击「获取」安装 金山文档拉取器。

02

打开脚本管理

在金山文档打开你的多维表格，进入 更多 → 脚本 → AirScript 脚本 → 管理脚本。

03

新建 AirScript 脚本

点击「+」旁的小三角，选择 新建 AirScript 1.0 脚本。注意编辑器右上角需为 API 1.0。

04

粘贴脚本代码

扩展向导内提供 一键复制脚本代码，粘贴进编辑器并保存。

05

生成令牌与链接

在脚本编辑器生成脚本令牌，并通过侧边栏「更多菜单」复制 webhook 链接。

06

填入配置，大功告成

打开扩展配置页，粘贴链接与令牌、填好字段名。点击工具栏图标，最新记录到手。

04 SECURITY

安全，是默认值

权限只申请必需项，通信只指向金山文档，配置只保存在你的浏览器里。

本地优先存储

所有配置仅保存在浏览器本地。跨设备迁移时以 6 位 PIN 加密后经浏览器账号云同步中转，不落地任何第三方数据库。

最小权限与直连

仅申请 storage / declarativeNetRequest / sidePanel 三项权限，网络访问限定 kdocs.cn 单一域名，请求不经任何中间服务器。

一键锁定

临时离开电脑？锁定后所有功能停用、不发起任何 webhook 请求；恢复使用需输入 PIN，用完即焚、不落盘保存。

05 FAQ

你可能想问

Q1支持哪些表格？
金山文档的多维表格与电子表格都支持。多维表格按字段名读取，调整列顺序或视图排序均不影响结果；电子表格会自动在任意行识别表头，无表头时可用 显示名=列字母（如 机构=E）定位。
Q2我的数据安全吗？
扩展只与 www.kdocs.cn 直连通信，没有任何第三方服务器参与；拉取动作由你账号里的脚本完成，权限边界就是你脚本本身的权限。配置存于本地，云迁移经 6 位 PIN 加密，锁定状态下零请求发出。
Q3为什么要部署脚本？麻烦吗？
这是它安全的原因：脚本跑在你自己的表格里，数据无需授权给任何外部应用。部署只需复制粘贴一次，扩展内置带截图的六步向导，全程约 5 分钟，之后一劳永逸。
Q4Chrome 或其他浏览器能用吗？
扩展基于 Manifest V3 标准开发，技术上兼容 Chromium 系浏览器；当前上架于 Edge 加载项商店，在 Microsoft Edge 中安装体验最佳。
Q5要付费吗？
扩展完全免费，无内购、无广告。使用金山文档需要你自己的账号（免费版即可）。
